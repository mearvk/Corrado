# Corrado Images (G60 & VR6)

Eight photographs of the Volkswagen Corrado — **4 G60** and **4 VR6** —
curated from **Wikimedia Commons** under Creative Commons licences.

## How to get the images

The image files are **not stored in this repository** (they are third-party
CC-licensed works). Fetch them to your machine with:

```sh
./images/fetch-images.sh
```

That downloads each file listed in [`images.manifest`](images.manifest) into
`images/g60/` and `images/vr6/`. (This sandbox has restricted networking, so
run the script on your own machine where internet access is open.)

## Why not commit the files directly?

These are other people's copyrighted photos, shared under CC licences that
require **attribution** (and, for ShareAlike, carrying the licence). Rather
than bake third-party binaries into the repo, we keep a **manifest + fetch
script** and a full **attribution table** below — you download the originals
from Commons, with their provenance intact.
