# Audio / Radio — European-market Corrado

Region-specific notes for the **European** Corrado's factory audio. For the
region-neutral systems and wiring reference, see the parent
[`audio/SYSTEMS.md`](../../SYSTEMS.md) and [`audio/WIRING.md`](../../WIRING.md).

## Head units (Europe)

- European cars shipped with VW's own-brand **"Alpha", "Beta" and "Gamma"**
  single-DIN cassette radios (built for VW by **Blaupunkt** and **Philips**),
  rising from basic (Alpha) to feature-rich (Gamma).
- Units are typically **code-protected**: a security **code** must be
  entered after any loss of power, or the radio locks. Keep the code card.
- Premium **"Sound System"** (external amp + door speakers/tweeters) was an
  option on better-equipped European cars.

## Tuner / band specifics

- **FM tuning step** and the **AM/LW/MW** band plan follow **European**
  broadcast standards (Europe historically includes **Long Wave**; the FM
  raster/step differs from the Americas).
- **RDS** (Radio Data System) appears on later/higher European units.
- A US-market head unit will **not** tune the European band plan correctly,
  and vice versa — this is the main reason a region-correct head unit matters
  for a numbers-matching restoration.

## Connector

- Same **VW/ISO** connector family as the rest of the range (pre-Quadlock) —
  see [`audio/WIRING.md`](../../WIRING.md). Wire colours follow the European
  loom; verify on the car.
